# Flight-Booking-Experience
Responsive static flight booking website with flight search, filtering, seat selection, booking summary, and localStorage booking history. Built using HTML, CSS, and JavaScript.

# ✈️ SkyWings — Next-Gen Flight Booking Experience

SkyWings is a responsive, feature-rich static web application designed to simplify the flight booking process. Built with modern UI/UX principles, the platform provides seamless flight search, filtering, seat map interaction, dynamic fare comparison, passenger details management, and persistent local storage.

## 🛠️ Tech Stack & Architecture

* **Frontend:** HTML5, Modern JavaScript (ES6+)
* **Styling:** Tailwind CSS (Utility-first CSS via CDN), FontAwesome Icons
* **Data Persistence:** Browser `localStorage` API
* **Version Control:** Git & GitHub
